# Three-minute demo guide

This guide describes the planned MVP journey; the current scaffold contains placeholders only.

1. **0:00–0:30 — Purpose:** Open the landing page and explain the shift from brain drain to brain circulation.
2. **0:30–1:00 — Preserve:** Visit the legacy timeline and filter fictional demonstration stories.
3. **1:00–1:40 — Contribute:** Enter a rough memory, use the Story Guide, review uncertainty labels and submit for moderation.
4. **1:40–2:10 — Moderate:** Open the demo admin area, compare rough and assisted text, then approve or request details.
5. **2:10–2:40 — Reconnect:** Filter the fictional alumni directory and record an engagement expression of interest.
6. **2:40–3:00 — Scale:** Show the impact page and clarify the proposed pilot, Caribbean expansion and no-endorsement notice.
